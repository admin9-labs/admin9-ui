# 组件体验优化：实施与整体复审

2026-10-07，基于当前工作区，按“操作语义与模式”“上传反馈与错误恢复”“文案与提示一致性”完成优化前方案的第一、第二批。未发布、未部署；所有服务操作验证使用本地 fake adapter。

## 用户最新约束

本轮最初按 UX-07 恢复了常显复选框和双行文件名，用户明确指出不应加回。已撤回：纯图片网格仅显示缩略图，隐藏常驻文件名与可见复选框，保留整卡选择、选中状态、键盘语义、预览和异常覆盖层；通用文件维持原单行名称、元信息和列表行高。删库确认中的名称与缩略图用于核对对象，保留。

图片卡片额外高度为 padding／border 的 20px；通用卡片为 72px；列表行高 66px。测试覆盖完整行分页、末页／空结果不缩短、视口变化和所有文件可达，不继续沿用已经撤回的双行几何。

## 整体复审发现与关闭

| 发现 | 修复 | 验证 |
| --- | --- | --- |
| 上传后的素材在当前页变 pending／failed／无效 URL，离开该页后会回退旧 ready 缓存 | 接受并保存最新已观察元数据及重复 ID 限制，换页／过滤不会恢复旧状态 | 3 个真实回归先失败，修复后通过 |
| A 上传成功、B 失败；管理删除／移动 A 后重试 B，会从旧成功任务复活 A 或覆盖 groupId | 删除标记和已合并成功任务集阻止旧记录覆盖；只合并新成功任务，保留管理更新 | 删除／移动各 1 个真实组合回归先失败，修复后通过 |
| 坐标错误保存翻译后的字符串，切换语言保留旧错误 | 保存原因标识，显示时翻译当前语言 | 搜索失败及地图／搜索不可用 zh→en 回归通过 |
| 经纬度 aria-label 落在 InputNumber 容器，原生 spinbutton 无名称 | 使用 Arco inputAttrs，直接设置原生输入标签 | 中文／英文原生 spinbutton 断言通过，浏览器按名称定位与输入成功 |
| 数量 1 显示 images／items 等复数 | 使用现有 vue-i18n 单复数分支，不引入配置层 | 实际数量 1／2 渲染回归通过，浏览器管理及删库正文验证通过 |
| 本库模板组预览回调有隐式 any | 使用有类型的回调，行为保持 | type:check 与预览／Modal 针对性验证通过 |
| 搜索选中地点后，仅聚焦再离开经纬度输入框会变成手动来源并丢失名称、地址 | 只有坐标实际变化时更新手动草稿；未修改输入保留原来源与地点元数据 | 纬度／经度各 1 条真实 Arco 回归先失败，修复后通过 |
| 成功上传记录在上传中或同批重试前被移除后，成功统计漏记或候选丢失 | 在成功任务快照到达时按任务 ID 合并；本批成功事实与队列显示分离，继续保护删除／移动和刷新元数据 | 上传中移除／重试前移除各 1 条回归先失败，修复后通过 |

独立只读复审确认原缓存问题与数量文案问题关闭；后续 review-agent 又发现上表两项 P2。已按用户授权修复并完成增量复审，当前没有未关闭的 P0–P2。纯图片网格仍按用户约束隐藏常驻文件名和可见复选框。

## 真实浏览器验收

使用 ego-browser，同一验证空间、仓库隔离 Vite 宿主。验收中没有通过 curl、DOM 桩或修改生产数据代替浏览器交互。

| 路径 | 实际验证结果 |
| --- | --- |
| 中文图片网格 | 文件名节点 0；卡片复选框为隐藏的可访问控件；桌面稳定区域宽 822px、15 个图片卡片可见；保留整卡选择和预览 |
| 管理 → 删除确认 → 取消 → 返回选择 | 管理标题和底部动作独立；确认显示素材库对象、名称、数量；取消不删库；返回恢复原草稿 |
| 已选一项 → 上传两项 → 选中本次上传 | 原选择保留，容量为 2 的字段只加入一项；剩余一项明确未选用、按钮禁用并解释上限；父字段 change／confirm 仍为 0 |
| 取消选择 | 上传到库的事实保留，字段未提交；显示已完成素材操作不会撤销的说明 |
| 英文管理和删除 | 1 item、1 selected image 正确；本库关闭按钮为 Close dialog |

## 接入要求与后续能力

另见 [组件体验接入要求](../components/experience-integration.md)。以下没有推入组件库：

- 删除永久性、回收站／撤销、素材引用影响、后端权限与实际文件验证。
- 编辑器 canSave 与业务表单保存、失败提示和服务端 HTML 清洗。
- 聊天发送禁用的真实原因、请求／重试以及业务空状态。
- 隐藏筛选条件摘要、重置后的业务默认值与重新查询时机。
- 表格搜索范围、刷新失败后的旧数据提示及业务复合刷新错误。
- 宿主 Arco／vue-i18n 语言同步、地图 Key／白名单／额度与坐标转换。

中文图标别名属于原方案 P3 的后续能力，本轮只明确现有英文名称检索与恢复，不虚称已支持中文语义搜索。
